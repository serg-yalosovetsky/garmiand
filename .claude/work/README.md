# Координация между агентами

Эта папка используется для предотвращения конфликтов между несколькими одновременно запущенными сессиями Claude Code.

## Когда создавать файл

Перед тем как начать нетривиальное редактирование (изменение ≥1 исходного файла), создай файл-заявку в этой папке. Сначала прочитай существующие файлы — если кто-то уже редактирует нужный тебе файл, скоординируйся с пользователем.

## Имя файла

Формат: `YYYYMMDD-HHMM-<краткое-описание>.md`

Пример: `20260511-1430-tile-rendering.md`

## Формат файла

```markdown
---
task: Краткое описание задачи
started: 2026-05-11 14:30
status: in-progress
files:
  - garmin/source/NavigationView.mc
  - garmin/source/TileDecoder.mc
---

Опционально: подход, ссылка на план.
```

Значения `status`: `in-progress` | `done` | `paused`

## Жизненный цикл

1. Создай файл **до** первого редактирования.
2. Удали файл (или поставь `status: done`) когда задача завершена.
3. Файлы старше 2 часов без изменений считаются устаревшими — можно игнорировать.

## Примечания

- Файлы `*.md` в этой папке добавлены в `.gitignore` — они не коммитятся.
- Этот `README.md` — исключение, он отслеживается в git.
